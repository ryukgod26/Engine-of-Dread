# Engine of Dread

This is my First First Person (fpv) game in godot. In This Game, You Will have to Open the Locker which is in the Basement But its password is randomly Generated and There is a Paper in which that Password is Written. You Will have to find the Paper in the House Under 2 Minutes and If You Fail You will Die and If You manage to open the locker before the 2 Minutes then You Win. This is not the full story of the Game There Will be a Creature or you can call it a Ghost Who Will be Following You In the Game. But Since all the assets in this Game are Created by me and I have never modelled anything before. The 3D Model of the creature is taking too much time. I have only managed to make its head till now. But In the future The Ghost will be introduced in the Game and the Story will also change. Most of the Objects in this game are interactble like closet and drawers.


## About the Project
I created this Project to learn how to make a 3d game in godot. That's why The game is very basic for now. But Io will Improve it in very soon. This is a horror game with red scene. For now the game is very basic and minimal.

## Project Structure

- `scenes/` — All game scenes are in this folder
- `scripts/` — All the game Script (gd script) files are in this folder.
- `assets/` — All the assets like models,Images are in this folder.
- `assets/Blender` — All The Blender Source Files and .glb files
- `Sounds/` — All the Sounds Used in this are in this folder.
